# POS 格式研究准则

## 已知范围

WPS 官方资料将 `.pos` 作为思维导图的导入、导出格式。公开资料没有提供当前 WPS 版本的完整 POS 文件规范，因此任何内部字段、压缩方式或版本标记都必须通过真实样本验证。

## 样本实验矩阵

每次只改变一个因素，并保存原始样本：

| 样本 | 唯一变化 | 用途 |
|---|---|---|
| A | 一个根主题 | 找到最小文档结构 |
| B | 根主题文字 | 定位文本字段和编码 |
| C | 增加一个子主题 | 定位父子关系和顺序 |
| D | 修改主题颜色 | 定位样式字段 |
| E | 增加一条关系线 | 定位非层级连接 |
| F | 增加备注或摘要 | 定位扩展内容 |

比较时分别检查文件头、容器目录、解压后的文本、二进制差异、生成 ID、时间戳和校验字段。不要把某一版本或某一专利的示例直接当成通用规范。

## 生成原则

1. 优先复制目标 WPS 版本导出的最小模板。
2. 只修改已被样本证明的字段。
3. 保留未知的包成员、元数据、顺序和版本字段。
4. 先生成根主题和一层子主题，再逐步加入样式、关系、摘要和备注。
5. 对文本使用明确的 Unicode 编码，并检查中文和特殊字符。
6. 稳定分配节点 ID、父节点 ID 和兄弟顺序。
7. 生成后必须通过 WPS 导入验证，静态可解析不等于 WPS 兼容。

## 图像到脑图的映射

- 中心对象或标题 → 根主题。
- 明确的模块层级 → 父子主题。
- 非层级箭头或依赖 → 关系线。
- 包围多个节点的范围 → 摘要或分组，前提是样本证明目标版本支持。
- 解释性文字 → 备注或标签，不要全部强行变成节点。
- 图表中的定量数据 → 独立保留数据源；脑图只表达其结构化结论。

## 验证记录

交付记录至少包含：

- WPS 产品和版本（若已知）。
- 使用的 POS 模板或样本。
- 文件容器和关键条目检查结果。
- WPS 导入结果。
- WPS 重新导出后的回读结果。
- 未识别文字、无法表达的图形和未验证字段。
