# WPS 图片研究与脑图重建 Skill

`wps-image-research` 用于把 PNG、JPG、截图或其他视觉参考资料拆解为可编辑的 WPS 思维导图 `.pos` 文件。它借鉴 `visio-image-rebuilder` 的“参考图分析—结构化重建—实际软件验证”流程，但目标产物改为 WPS 脑图格式。

## 重要说明

`.pos` 是 WPS 思维导图的专用格式，不是通用图片格式。WPS 没有公开完整且稳定的 POS 文件规范，因此不能仅凭扩展名、专利示例或猜测的 JSON/ZIP 结构声称生成文件兼容 WPS。最可靠的方式是使用目标 WPS 版本导出的 `.pos` 作为模板，再进行样本驱动的差异分析和验证。

## 适用场景

- 从流程图、架构图、研究图或截图提取层级并生成可编辑脑图。
- 保留根主题、分支、子节点、关系线、摘要、标签和说明文字。
- 研究现有 `.pos` 文件的容器结构、节点字段和版本差异。
- 修改已有 POS 文件的主题、层级、颜色、样式或布局。
- 通过 WPS 导入和重新导出验证生成结果。

不适合把照片、复杂定量图表或像素级插画直接转换成脑图，也不允许把整张参考图片嵌入 POS 文件来冒充可编辑重建。

## 推荐用法

```text
使用 wps-image-research，把这张架构图重建为可编辑的 WPS 思维导图 .pos。保留所有模块层级、关系线和中文标签；不要嵌入整张图片，并用 WPS 导入验证。
```

```text
分析这个 WPS .pos 样本的结构，基于它生成一份新的脑图。不要修改原文件，完成后说明是否经过 WPS 导入和重新导出验证。
```

## 交付前检查

- 使用了真实 WPS 样本或明确说明无法证明格式兼容。
- WPS 的“导入思维导图”可以正常载入文件。
- 根主题、层级、顺序、重点标签和关系线均保留。
- 导入后的主题仍可单独编辑，中文编码正常。
- 没有整页参考图作为底图。
- 原始图片、POS 样本和用户文档未被覆盖。
- 如果 WPS 不可用，明确区分静态检查与实际兼容性验证。
